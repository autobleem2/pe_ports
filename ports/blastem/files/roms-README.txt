Your Mega Drive / Genesis games go here: ROM files (.bin .md .gen .smd, also .zip), Master System and Game Gear
games (.sms .gg) and the other formats BlastEm lists. This package does not contain any game and does not download one.

BlastEm opens this folder first (Load ROM in its menu). Homebrew games (made by hobbyists, free to share) work the
same way: put the file here.

Pad: Cross, Circle, Square = A, B, C; Triangle, L1, R1 = X, Y, Z (6 button games); Start = Start; Select = Mode;
L2 or R2 = BlastEm's menu (save state, load state, reset, settings, exit).
